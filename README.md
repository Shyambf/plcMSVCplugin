# Visual Studio Extension: Planning C 2.0 Language Support & Native Debugger

[![Build and Release VSIX](https://github.com/Shyambf/plcMSVCplugin/actions/workflows/build-release.yml/badge.svg)](https://github.com/Shyambf/plcMSVCplugin/actions/workflows/build-release.yml)
[![Visual Studio](https://img.shields.io/badge/Visual%20Studio-2022%20%7C%202026-blue.svg)](https://visualstudio.microsoft.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Расширение для Microsoft Visual Studio 2022 и Visual Studio 2026, реализующее полноценную подсветку синтаксиса, языковую поддержку и **нативный визуальный отладчик с отображением состояния потоков** для языка параллельного конвейерного программирования и автоматического планирования **Planning C 2.0**.

---

## Возможности

- **Полная поддержка синтаксиса Planning C 2.0**:
  - **Конвейеры и реентрабельность**: `reenterable`, `chain`, `throw`, `throw_stage`, `throw_first`, `throw_last`, `_Yield`, `global`, `local`;
  - **Функции планирования**: `plan_first`, `plan_last`, `plan_get_first`, `plan_empty`, `plan_after_continue`, `plan_group_*`, `reent_*`;
  - **Каналы данных и очереди**: `funnel`, `cfunnel`, `cvar`, `csem`, `input_proc`;
  - **Виртуальные топологии**: `hypercube`, `torus`, `grid`, `ring`, `clique`, `tree`, `sun`;
  - **Встроенный Prolog и предикаты**: правила `@goal`, `@rule`, оператор `:-`, предикаты `xpathf`, `similar`, `gid`, `brackets_off`;
  - **Естественно-языковое метапрограммирование (РЯП / ЯОП)**: предложения `#(Составить программу.)`, склонения существительных-типов (`вектор`, `матрица`, `скаляр`, `элемент`) и глаголов-действий (`ввести`, `найдем`, `поместим`, `вывести`);
  - **Директивы мета-транслятора**: `#def_pattern`, `#def_module`, `#def_xpath`, `#introduce`, `#stop`, `#scan`;
  - **Параллелизм в стандарте Cilk++**: `cilk_spawn`, `cilk_sync`, `cilk_for`.
- **Конфигурация токенов через JSON ([`syntax_rules.json`](plcMSVCplugin/syntax_rules.json))**:
  - Все ключевые слова, типы, каналы, препроцессор и термины РЯП вынесены в удобный JSON-файл;
  - Добавление новых токенов не требует правок C#-кода и регулярных выражений.
- **Нативная работа со стандартными файлами .cpp (ISO C99/C11 / C++)**:
  - Вся разработка и примеры языка ведутся непосредственно в стандартных файлах `.cpp` (а также `.h`);
  - Плагин автоматически подсвечивает синтаксис Planning C в любых `.cpp` файлах без необходимости переименования или создания отдельных расширений.
- **Нативный MEF-классификатор**:
  - Высокая скорость работы без задержек (`RegexOptions.Compiled`);
  - Прямое подключение к стандартному редактору кода Visual Studio (`Source Code Editor`) без конфликтов TextMate COM.
- **Нативный визуальный отладчик Planning C 2.0**:
  - Запуск отладки в один клик (`Shift+Alt+F5`, кнопка на Toolbar, верхнее меню и контекстное меню редактора);
  - **Запуск без отладки (`Ctrl+F5`)**: сборка и запуск программы в интерактивной консоли без подключения отладчика;
  - **Всплывающие подсказки QuickInfo & DataTips**: просмотр состояния и очередей каналов (`funnel`, `cfunnel`), разделяемых переменных (`cvar`) и стадии (`throw_stage`) прямо при наведении курсора в редакторе кода;
  - **Очистка файлов сборки**: удаление временных файлов `.obj`, `.exe`, `.pdb`, `_out.cpp` в каталоге `.plc_build` в один клик;
  - Пошаговое выполнение прямо по исходному коду `.cpp` благодаря директивам `#line` и нативному `.pdb`;
  - Окно «Инспектор плана и потоков» с инспекцией потоков процесса, стадий конвейера, воронок и топологий;
  - Natvis-визуализаторы ([`PlanningC.natvis`](plcMSVCplugin/PlanningC.natvis)) для стандартных окон Watch/Locals/Autos.

## Нативный отладчик Planning C и инструменты запуска

### 1. Запуск отладки (Debug, Shift+Alt+F5)
- Нажмите кнопку **«Отладка»** на главной панели инструментов Visual Studio или в окне Инспектора плана;
- Или используйте пункт в меню **«Отладка -> Запуск отладки Planning C»**;
- Или выберите **«Запуск отладки Planning C»** в контекстном меню (правый клик в редакторе `.cpp`);
- Или нажмите горячую клавишу **`Shift+Alt+F5`**.

Плагин автоматически сохранит документ, запустит транслятор `Reenterable.exe`, нормализует директивы `#line` для исключения виртуальных макросов `PATTERN[...]`, скомпилирует отладочный `.exe` и `.pdb` через MSVC (`cl.exe /Zi`) и подключит штатный нативный отладчик Visual Studio.

### 2. Запуск без отладки (Run Without Debugging, Ctrl+F5)
- Нажмите кнопку **«Без отладки»** на панели инструментов или в окне Инспектора плана;
- Или используйте пункт в меню **«Отладка -> Запуск Planning C без отладки»**;
- Или выберите в контекстном меню редактора;
- Или нажмите горячую клавишу **`Ctrl+F5`**.

Программа компилируется и запускается в отдельном интерактивном окне командной строки с паузой после завершения.

### 3. Очистка файлов сборки (.plc_build)
- Нажмите кнопку **«Очистить .plc_build»** в окне Инспектора плана;
- Или выберите **«Отладка -> Очистить файлы сборки Planning C (.plc_build)»** / пункт контекстного меню редактора.

Плагин удалит сгенерированные файлы `_out.cpp`, `.obj`, `.exe`, `.pdb` и освободит дисковое пространство.

### 4. Визуальный отклик и мониторинг прогресса сборки
Плагин обеспечивает непрерывную обратную связь в процессе трансляции и компиляции:
- **Мгновенный отклик UI:** при нажатии кнопок запуска курсор переключается в режим ожидания (`Wait`), кнопки защищаются от повторного нажатия, а индикатор состояния инспектора немедленно загорается оранжевым цветом (`«Сборка Planning C...»`);
- **Автоматическое всплытие окна «Вывод» (Output Window):** при старте сборки окно «Вывод» автоматически открывается и переключается на вкладку **Planning C**, транслируя лог работы `Reenterable.exe` и `cl.exe` вживую;
- **Индикация в строке состояния (Status Bar):** в нижнем левом углу Visual Studio запускается анимация сборки и отображается прогресс-бар:
  - `[1/3] Трансляция через Reenterable.exe...`
  - `[2/3] Компиляция C++ через cl.exe...`
  - `[3/3] Запуск программы / Подключение отладчика...`
- **Защита от зависаний (Timeout Protection):** процессы трансляции и компиляции защищены настраиваемым сторожевым таймером. В случае зацикливания парсера процесс принудительно завершается, предотвращая блокировку Visual Studio;
- **Умное определение активного документа:** плагин корректно находит открытый файл с кодом Planning C, даже если перед нажатием кнопки фокус находился в окне инспектора плана или проводнике решений.

### 5. Всплывающие подсказки QuickInfo и Hover DataTips
- **В режиме отладки (Break Mode)**: при наведении мыши на воронку (`funnel`, `cfunnel`), защищенную переменную (`cvar`) или `throw_stage`, отображается интерактивная карточка DataTip с текущим значением, количеством буферизованных сообщений и содержимым очереди `Data[0]`.
- **В режиме редактирования кода**: при наведении курсора на ключевые слова и типы Planning C (`funnel`, `reenterable`, `chain`, `throw`, `markupdef` и др.) отображается документация с пояснением семантики языка.

### 6. Окно «Инспектор плана и состояния потоков»
Окно автоматически активируется при остановке программы на точке останова (Break Mode), либо может быть открыто вручную через **Вид -> Другие окна -> Инспектор плана и потоков Planning C**:
- **Вкладка «Потоки и стадии (Threads)»**: список всех потоков программы (`ID`, имя, состояние, выполняемая функция, приоритет) и просмотр стека вызовов выбранного потока;
- **Вкладка «Инспектор плана (Planning C)»**: стадии конвейера (`reent_stage`, `throw_stage`), число стадий (`reent_num_stages`), состояние очередей плана (`plan_first`, `plan_last`, `plan_empty`);
- **Вкладка «Каналы данных (funnel / cfunnel)»**: активные воронки в рантайме, их емкость, текущее заполнение, просмотр элементов `Data[]` и блокировки;
- **Вкладка «Топология (Topology)»**: текущий процессор (`plan_processor_id`), число процессоров (`plan_processors`), статус топологии;
- **Вкладка «Журнал сборки (Log)»**: подробный вывод процесса трансляции и компилятора MSVC.

### 7. Natvis-визуализаторы для окон Watch / Locals
Файл [`PlanningC.natvis`](plcMSVCplugin/PlanningC.natvis) встроен в расширение и автоматически регистрируется в отладчике Visual Studio. Типы данных `_funnel`, `funneled_in`, `funneled_out`, `cfunnel`, `reent_list`, `__Topology`, `TVar` форматируются в окнах Locals и Watch в человекочитаемом виде (емкость, элементы, размер, статусы).

## Настройки плагина

В Visual Studio откройте **Сервис -> Параметры -> Planning C -> Debugger and Translator**:
- **Путь к транслятору (Reenterable.exe)**: путь к исполняемому файлу транслятора (поддерживается диалог обзора `[...]`; по умолчанию находится автоматически в каталоге проекта/решения);
- **Каталоги заголовков (Include Directories)**: пути к заголовочным файлам Planning C (`reentera.h`, `memoization.h` и т.д., кнопка обзора папки `[...]`);
- **Путь к vcvars64.bat / cl.exe**: путь к среде компилятора MSVC (находится автоматически для VS 2026/2022, кнопка обзора `[...]`);
- **Флаги компилятора C++**: флаги сборки отладочной версии (по умолчанию: `/EHsc /openmp /std:c++17 /Zi /Od /MDd`);
- **Таймаут транслятора (сек)**: максимальное время ожидания завершения `Reenterable.exe` в секундах (по умолчанию: `15` сек);
- **Таймаут компилятора C++ (сек)**: максимальное время ожидания компилятора `cl.exe` (по умолчанию: `30` сек);
- **Подпапка для файлов сборки**: имя подкаталога рядом с исходником (по умолчанию: `.plc_build`);
- **Автосохранение перед запуском**: автоматически сохранять файл перед вызовом отладчика;
- **Открывать инспектор плана при останове**: активировать окно инспектора при Break Mode.

## Установка

1. Скачайте файл **`PlanningC.vsix`** из раздела [Releases](https://github.com/Shyambf/plcMSVCplugin/releases) (или соберите его локально из исходников).
2. Закройте Visual Studio и запустите файл `PlanningC.vsix` двойным кликом.
3. В окне `VSIX Installer` нажмите **Install**.
4. После завершения откройте Visual Studio и откройте любой `.cpp` файл (например, тестовые примеры `test_samples/test_syntax.cpp` или `test_samples/reent.cpp`).

Подробная инструкция: [INSTALL.md](INSTALL.md).

> [!TIP]
> **Рекомендация:** Чтобы встроенный C++ семантический анализатор IntelliSense не перекрашивал специфичные конструкции языка Planning C (`reenterable`, `chain` и т.д.) в стандартный цвет текста, рекомендуется отключить параметр: *Сервис -> Параметры -> Текстовый редактор -> C/C++ -> Дополнительно -> Цветовая схема IntelliSense -> «Окрашивать токены на основании IntelliSense» = False*. Подробнее в [INSTALL.md](INSTALL.md).

## Сборка из исходного кода

Для самостоятельной сборки потребуется .NET SDK (рекомендуется .NET 8 SDK или выше):

```powershell
# Вариант 1: Запуск встроенного PowerShell скрипта
.\build_vsix.ps1

# Вариант 2: Сборка через .NET CLI
dotnet build plcMSVCplugin/plcMSVCplugin.csproj -c Release
```

Скомпилированный файл расширения сохраняется в:
`plcMSVCplugin/bin/Release/net472/PlanningC.vsix` и копируется в корень репозитория под именем `PlanningC.vsix`.

## Разработчикам: Доработка синтаксиса языка

Если вы дорабатываете язык Planning C и вам требуется добавить новые ключевые слова, типы, мета-директивы или операторы:
- Все токены редактируются в файле конфигурации [`plcMSVCplugin/syntax_rules.json`](plcMSVCplugin/syntax_rules.json);
- Править C#-код не требуется;
- Подробные инструкции и описание разделов приведены в [Руководстве разработчика (MANUAL.md)](MANUAL.md).
