# Руководство разработчика: Добавление ключевых слов и доработка синтаксиса

Данное руководство кратко освещает вопрос о том, как вносить изменения в плагин Planning C при введении нового ключевого слова, типа данных, директивы препроцессора или оператора в язык, и как настроить для него подсветку.

---

## Архитектура подсветки синтаксиса

Язык Planning C строится поверх стандартного C/C++ (ISO C99/C11 / C++). Вся разработка и примеры ведутся непосредственно в стандартных файлах **`.cpp`** (и `.h`).

В плагине используется **нативный MEF-классификатор (`PlanningCClassifier.cs`)**:
- Он напрямую подключается к встроенному редактору C/C++ Visual Studio (`Source Code Editor`);
- Не требует никаких промежуточных JSON/TextMate грамматик и сторонних манифестов;
- Все правила и ключевые слова собраны в **одном файле** — [`PlanningCClassifier.cs`](plcMSVCplugin/PlanningCClassifier.cs).

---

## Как добавить новое ключевое слово в язык

Чтобы добавить подсветку для нового слова, нужно отредактировать всего **один файл** — `plcMSVCplugin\PlanningCClassifier.cs`.

### Шаг 1. Откройте `PlanningCClassifier.cs`
В файле найдите регулярное выражение `MasterTokenRegex` (строка ~50):

1. **Ключевое слово управления, планирования или параллелизма (синяя подсветка)**:
   Найдите блок `// 10. Ключевые слова планирования и C++` (`(?<keyword>\b(?:...)\b)`) и добавьте слово через разделитель `|`:
   ```csharp
   @"plan_first|plan_last|plan_get_first|plan_get_last|plan_empty|моё_новое_слово|" +
   ```

2. **Новый тип данных, виртуальная топология или канал (бирюзовая подсветка как `vector`)**:
   Найдите блок `// 9. Типы данных, каналы и топологии` (`(?<type>\b(?:...)\b)`) и добавьте тип через `|`:
   ```csharp
   @"funnel|cfunnel|cvar|мой_новый_канал|" +
   ```

3. **Новая директива препроцессора `#...`**:
   Найдите блок `// 4. Директивы (#...)` (`(?<preproc>#\s*(?:...)\b)`) и добавьте название директивы без знака `#`:
   ```csharp
   @"def_pattern|def_module|моя_директива|" +
   ```

4. **Новые слова для русского естественно-языкового программирования `#( ... )`**:
   - Существительное/тип: добавьте в `// 6. Типы РЯП` (`(?<ru_type>...)`).
   - Глагол/действие: добавьте в `// 7. Действия РЯП` (`(?<ru_keyword>...)`).

5. **Новый составной оператор языка** (например, `<~>` или `:=`):
   Добавьте его в `// 13. Операторы` (`(?<operator>...)`).

## Настройка цвета токена (при необходимости)

Если токен добавлен в одну из существующих групп (`keyword`, `type`, `preproc`, `operator`), цвет применится автоматически.

Если вам нужна отдельная группа токенов:
В методе `GetClassificationSpans` привяжите группу к желаемому типу подсветки:
- `keywordType` — Синий (ключевые слова)
- `typeType` — Бирюзовый / Зеленый (типы данных и топологии)
- `preprocessorType` — Фиолетовый / Синий (директивы препроцессора)
- `operatorType` — Серый / стандартный (операторы)
- `commentType` — Зеленый (комментарии)
- `stringType` — Коричнево-красный (строки)
- `numberType` — Светло-зеленый (числа)

## Шаг 2. Сборка и проверка

После внесения изменений запустите скрипт пересборки:
```powershell
.\build_vsix.ps1
```
или выполните:
```powershell
dotnet build plcMSVCplugin/plcMSVCplugin.csproj -c Release
```
Скрипт пересоберет расширение и обновит файл `PlanningC.vsix` в корне репозитория.
Установите его и проверьте подсветку нового синтаксиса в тестовом файле `plcMSVCplugin\test_samples\test_syntax.cpp`.
