# Release Notes — Planning C Visual Studio Extension v1.2.0

### Новые возможности и компоненты плагина:
1. **Интеграция запуска и отладки Planning C в Visual Studio:**
   - Команда «Запуск отладки Planning C» (`Shift+Alt+F5`): автоматическое сохранение документа, вызов транслятора `Reenterable.exe`, компиляция через `cl.exe` с генерацией отладочных символов (`.pdb`) и запуск с автоматическим подключением штатного отладчика Visual Studio к процессу.
   - Команда «Запуск Planning C без отладки» (`Ctrl+F5`): компиляция и запуск исполняемого файла в отдельной консоли с удержанием окна до нажатия клавиши.
   - Команда «Очистить артефакты сборки Planning C»: удаление промежуточных файлов и исполняемых бинарников в подкаталоге сборки.
   - Интеграция команд в главное меню «Отладка» (Debug), «Сборка» (Build), а также в контекстное меню редактора кода C++.

2. **Страница настроек (Tools -> Options -> Planning C):**
   - Возможность явного указания путей к `Reenterable.exe`, каталогам include-заголовков и скрипту `vcvars64.bat` / `cl.exe`.
   - Настраиваемые таймауты выполнения транслятора (по умолчанию 15 секунд) и компилятора `cl.exe` (по умолчанию 30 секунд) с автоматическим прерыванием зависших процессов.
   - Настраиваемые флаги компилятора C++ с автоматическим обеспечением 8 МБ стека (`/F8388608`) для предотвращения переполнения стека в многопоточных и рекурсивных программах OpenMP.
   - Настройка имени подкаталога для файлов сборки (по умолчанию `.plc_build`).

3. **Инспектор планов (Plan Inspector Tool Window):**
   - Инструментальное окно Visual Studio («Вид -> Другие окна -> Инспектор планов Planning C») на базе WPF для мониторинга очередей событий `plan_first`/`plan_last`, топологий конвейеров и стадий выполнения.

4. **IntelliSense QuickInfo и подсказки:**
   - Подсказки QuickInfo для ключевых слов и макросов Planning C (`reenterable`, `plan_first`, `plan_last`, `plan_group_parallelize`, `plan_parallel_chain` и др.).

5. **Визуализаторы отладчика (Natvis):**
   - Добавлен файл `PlanningC.natvis` с удобным отображением внутренних структур рантайма в окнах Watch, Locals и DataTips: списков `reent_list<T>`, `circular_list<T>`, узлов топологий `NetNode`, деревьев `TreeNode` и элементов `DataItem`.

6. **Оптимизация и исправление тестовых примеров:**
   - В примере `reent.cpp` устранены бесконечная рекурсия и переполнение стека в алгоритме сортировки срезов: оптимизирован размер кадра стека с 32 КБ до 32 байт и исправлен расчёт опорного элемента.
   - Добавлены тестовые примеры `simple_conveyor.cpp`, `simple_fibb.cpp`, `test_syntax.cpp`.

7. **Документация проекта:**
   - Полностью обновлены руководства `README.md`, `INSTALL.md` и `MANUAL.md` с описанием архитектуры, шагов сборки VSIX, хоткеев и параметров конфигурации.
