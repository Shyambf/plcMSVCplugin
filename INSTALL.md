# Инструкция по установке и тестированию плагина Planning C


---

## Совместимость
- **Visual Studio 2022** (Community, Professional, Enterprise — версия 17.0 и выше)
- **Visual Studio 2026** (версия 18.0 и выше)
- Архитектура: **x64 (amd64)**

---

## Вариант 1. Установка из готового релиза (GitHub Releases)

Этот вариант рекомендуется для повседневного использования плагина.

1. Перейдите в раздел **[Releases](https://github.com/Shyambf/plcMSVCplugin/releases)** репозитория на GitHub.
2. В последнем релизе скачайте прикрепленный файл **`PlanningC.vsix`** (или соберите его локально по Варианту 2).
3. **Закройте Visual Studio**, если она запущена.
4. Запустите скачанный файл **`PlanningC.vsix`** двойным щелчком мыши.
5. В открывшемся окне установщика `VSIX Installer` выберите вашу версию Visual Studio (например, *Visual Studio Community 2022*) и нажмите **Install**.
6. Дождитесь появления сообщения об успешной установке и закройте установщик.
7. Запустите Visual Studio.
8. Откройте любой `.cpp` файл с кодом Planning C (например, `test_samples/test_syntax.cpp` или файлы из папки примеров `Examples`).

---

## Вариант 2. Тестирование и сборка через Git Clone

Этот вариант предназначен для разработчиков, контрибьюторов и локального тестирования.

### Шаг 1. Клонирование репозитория
Откройте терминал (PowerShell или Git Bash) и выполните:
```bash
git clone https://github.com/Shyambf/plcMSVCplugin.git
cd plcMSVCplugin
```

### Шаг 2. Сборка VSIX пакета
Сборка выполняется средствами .NET SDK без каких-либо сторонних интерпретаторов.

**Способ А (через встроенный скрипт PowerShell):**
```powershell
.\build_vsix.ps1
```

**Способ Б (напрямую через .NET CLI):**
```powershell
dotnet build plcMSVCplugin/plcMSVCplugin.csproj -c Release
```

Скрипт соберет проект и скопирует готовый пакет **`PlanningC.vsix`** в корень репозитория.

### Шаг 3. Установка скомпилированного пакета
Закройте Visual Studio и запустите установку:
```powershell
Start-Process .\PlanningC.vsix
```
Или дважды кликните по файлу `PlanningC.vsix` в Проводнике Windows и нажмите **Install**.

### Шаг 4. Проверка и тестирование подсветки в `.cpp`
1. Запустите Visual Studio;
2. Откройте готовый тестовый файл:
   `plcMSVCplugin\test_samples\test_syntax.cpp`
3. Убедитесь, что все ключевые конструкции Planning C корректно подсвечиваются:
   - **Конвейеры и реентрабельность**: `reenterable`, `chain`, `throw`, `_Yield`
   - **Функции плана**: `plan_first`, `plan_last`, `plan_empty`, `plan_group_*`, `reent_*`
   - **Каналы и семафоры**: `funnel`, `cfunnel`, `cvar`, `csem`, `input_proc`
   - **Виртуальные топологии**: `hypercube`, `torus`, `grid`, `ring`, `clique`, `tree`, `sun`
   - **Встроенный Prolog и предикаты**: `@goal`, `@rule_name`, `:-`, `xpathf`, `brackets_off`
   - **Русский язык описания программ (РЯП)**: `#(Составить программу.)`, склонения `вектор`, `матрица`, действия `ввести`, `найдем`, `поместим`
   - **Параллелизм Cilk++**: `cilk_spawn`, `cilk_sync`, `cilk_for`

### Шаг 5. Запуск и отладка примеров
В репозиторий включены готовые к запуску и отладке примеры:
- `plcMSVCplugin\test_samples\simple_conveyor.cpp` — параллельный конвейер с обменом данными через каналы `funnel(in, int)` и `funnel(out, int)`;
- `plcMSVCplugin\test_samples\simple_fibb.cpp` — вычисление чисел Фибоначчи с автоматической мемоизацией `#pragma memoization(i)`;
- `plcMSVCplugin\test_samples\reent.cpp` — построение и обход дерева с планированием задач (`PutTree`, `plan_first`), просмотр плана в табличном виде и пошаговая отладка;
- `plcMSVCplugin\test_samples\reent_while_else.cpp` — развертывание дедуктивного макроса (`while_else`), установка точек останова и пошаговая трассировка.

**Способы запуска:**
1. **Запуск без отладки (`Ctrl+F5`):**
   - Нажмите `Ctrl+F5` или кнопку **«Без отладки»** на панели инструментов / в окне Инспектора плана.
   - Программа скомпилируется и запустится в консоли Windows.
2. **Запуск с нативной отладкой (`Shift+Alt+F5`):**
   - Поставьте точку останова (F9) в коде `.cpp`.
   - Нажмите `Shift+Alt+F5` или кнопку **«Отладка»**.
   - Отладчик остановится точно на вашей точке останова в `.cpp` файле.

**Где смотреть прогресс сборки:**
- **Окно «Вывод» (Output Window):** при запуске автоматически всплывает вкладка **Planning C**, где в реальном времени бежит подробный лог трансляции и компиляции.
- **Строка состояния (Status Bar внизу окна):** отображает анимацию сборки и пошаговый прогресс `[1/3] Трансляция...` -> `[2/3] Компиляция...` -> `[3/3] Запуск...`.
- **Настройки путей и таймаутов:** меню **Сервис -> Параметры -> Planning C** позволяет настроить путь к `Reenterable.exe` через кнопку обзора `[...]` и изменить таймаут трансляции (по умолчанию 15 сек).

## Настройка IntelliSense для идеальной подсветки Planning C

Поскольку Planning C является надстройкой над C++ со своими расширениями синтаксиса, стандартный семантический анализатор C++ IntelliSense в Visual Studio не знает о конструкциях вроде `reenterable` или `chain`. Спустя несколько секунд после открытия файла IntelliSense может попытаться переопределить подсветку неизвестного ему токена стандартным цветом текста.

Чтобы подсветка плагина всегда отображалась корректно и без конфликтов:
1. В Visual Studio откройте меню: **Сервис** (Tools) -> **Параметры** (Options);
2. Перейдите в раздел: **Текстовый редактор** (Text Editor) -> **C/C++** -> **Дополнительно** (Advanced);
3. В категории **Цветовая схема IntelliSense** (IntelliSense Color Scheme) отключите параметр:
   - **Окрашивать токены на основании IntelliSense** (Colorize based on IntelliSense) = **False / Ложь**.
4. *(Опционально)*: Чтобы IntelliSense не подчеркивал специфичные конструкции языка красными волнистыми линиями, в этой же вкладке в блоке **IntelliSense** можно включить:
   - **Отключить волнистые линии ошибок** (Disable Squiggles) = **True / Истина**.

## Управление и удаление расширения

В Visual Studio откройте верхнее меню:
`Расширения` (Extensions) -> `Управление расширениями` (Manage Extensions) -> вкладка `Установленные` (Installed).

Здесь вы можете:
- **Отключить (Disable)** плагин при необходимости;
- **Удалить (Uninstall)** плагин из системы.
