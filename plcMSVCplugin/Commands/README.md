# Подсистема команд Visual Studio (Commands)

В этой папке сосредоточены все обработчики команд пользователя: пункты главного меню, контекстных меню и комбинации горячих клавиш.

> Полное руководство и спецификация команд: [Commands.md](Commands.md).

---

## Архитектура команд в Visual Studio SDK

Связывание команд между интерфейсом Visual Studio и C# кодом работает по двухзвенной схеме:

1. **Декларативное описание (VSCT):**  
   В файле `plcMSVCpluginPackage.vsct` задаются идентификаторы меню, кнопок и горячих клавиш:
   * Набор команд: `guidplcMSVCpluginPackageCmdSet` (`298516d5-a337-4bf7-bfeb-433a08892f25`).
   * Каждой кнопке сопоставлен свой целочисленный идентификатор `CommandId`.

2. **Программная регистрация (C#):**  
   В методе `InitializeAsync` класса пакета `plcMSVCpluginPackage.cs` для каждой команды вызывается статический метод инициализации:
   ```csharp
   await StartPlanningCDebugCommand.InitializeAsync(this);
   await RunPlanningCCommand.InitializeAsync(this);
   await OpenPlanInspectorCommand.InitializeAsync(this);
   await CleanPlcBuildCommand.InitializeAsync(this);
   ```

## Сводная таблица горячих клавиш (Hotkeys)

| Сочетание клавиш | Команда / Действие | Область действия | Описание |
| :--- | :--- | :--- | :--- |
| **`Shift+Alt+F5`** | **Запуск отладки Planning C** | Глобально в IDE / Редактор `.cpp` | Сохраняет файл, запускает транслятор `Reenterable.exe`, выполняет постобработку директив `#line`, компилирует отладочный `.exe` и `.pdb` через `cl.exe /Zi` и подключает нативный отладчик Visual Studio. |
| **`Ctrl+F5`** | **Запуск Planning C без отладки** | Глобально в IDE / Редактор `.cpp` | Быстрая компиляция и запуск в интерактивном окне консоли Windows (`cmd.exe`) с удержанием экрана (`pause`). |
| **`Shift+Alt+P`** | **Инспектор плана Planning C** | Глобально в IDE | Открывает или делает активным инструментальное окно Инспектора плана (`PlanInspectorToolWindow`). |
| **`F9`** | **Точка останова (Breakpoint)** | Редактор `.cpp` | Устанавливает или снимает точку останова на строке исходного кода Planning C. Благодаря нормализации `#line` точка останова привязывается к реальному коду без сбоев. |
| **`F10`** | **Шаг с обходом (Step Over)** | Режим отладки (Break Mode) | Выполняет текущую строку без захода во внутренние вызовы функций. Благодаря изоляции выхода не проваливается в соседние процедуры рантайма. |
| **`F11`** | **Шаг с заходом (Step Into)** | Режим отладки (Break Mode) | Заходит внутрь вызываемой реентрабельной процедуры или функции планирования. |
| **`Shift+F11`** | **Шаг с выходом (Step Out)** | Режим отладки (Break Mode) | Выполняет оставшийся код текущей функции и останавливается сразу после возврата в вызывающий контекст. |
| **`Shift+F5`** | **Остановить отладку (Stop)** | Режим отладки (Break Mode / Run Mode) | Принудительно завершает процесс отладки и освобождает скомпилированные бинарные файлы. |
| **`Ctrl+Shift+F5`** | **Перезапуск (Restart)** | Режим отладки (Break Mode) | Перезапускает процесс отладки с начала программы. |

## Состав файлов

### 1. `StartPlanningCDebugCommand.cs`
* **Команда:** «Запуск отладки Planning C»
* **ID:** `0x0100`
* **Горячие клавиши:** `Shift+Alt+F5`
* **Назначение:**  
  Инициирует полный цикл сборки активного файла Planning C (.cpp), накладывает исправления директив `#line` и подключает нативный отладчик Visual Studio. При падении или остановке на точке останова отладчик передает управление редактору.

### 2. `RunPlanningCCommand.cs`
* **Команда:** «Запуск Planning C без отладки»
* **ID:** `0x0101`
* **Горячие клавиши:** `Ctrl+F5`
* **Назначение:**  
  Собирает проект и запускает скомпилированный бинарный файл в отдельном интерактивном окне консоли Windows (с паузой `pause`).

### 3. `OpenPlanInspectorCommand.cs`
* **Команда:** «Инспектор плана Planning C»
* **ID:** `0x0102`
* **Горячие клавиши:** `Shift+Alt+P`
* **Назначение:**  
  Открывает или делает активным инструментальное окно Инспектора плана (`PlanInspectorToolWindow`).

### 4. `CleanPlcBuildCommand.cs`
* **Команда:** «Очистить файлы сборки Planning C (.plc_build)»
* **ID:** `0x0103`
* **Назначение:**  
  Безопасно удаляет промежуточные файлы из подпапки `.plc_build`.
